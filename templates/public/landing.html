Security & reliability

Guardrails are part of the architecture.

ServerPilot treats isolation, ownership and auditability as product requirements — not add-ons.

Only controls implemented in the current platform are described here.
  • Isolated application deployments

    Applications run in dedicated containers with explicit resource boundaries.

  • User-level access control

    Ownership is checked server-side for every website, deployment and setting.

  • Protected environment variables

    Sensitive values are encrypted at rest and never rendered into the public interface.

  • Secure agent communication

    Deployment tasks are signed and verified before an agent executes them.

  • Resource quotas

    RAM, storage and website slots are enforced across the account.

  • Audited administrative operations

    Operator actions and authentication events are recorded.

  • Controlled deployment permissions

    Deployment authorization can require an explicit administrator step.
