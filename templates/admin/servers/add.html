Security model

What happens during provisioning.

  • The control plane validates the target and rejects loopback, link-local, multicast and reserved addresses unless an explicit network allowlist is configured.
  • The SSH host key is checked against the SHA256 fingerprint or the server-side known_hosts file before authentication succeeds.
  • Discovery runs only a fixed, read-only command allowlist. Request values are never interpolated into shell commands.
  • Agent enrollment uses a short-lived, single-use token. The agent receives its own credential; the SSH key is not copied to the host.
  • The agent runs as a dedicated non-root user with a restricted sudo rule for Nginx validation and reload only.
  • New servers stay pending until an administrator reviews the scan and approves them.
