What this protects

Deployment approval is enforced server-side by @admin_deployment_required on destructive operations.

  • Website start/stop/restart and deployment actions remain separate from viewing dashboards.
  • A linked GitHub identity can be used when no email is exposed by the provider.
  • Unverified provider emails never satisfy the approval gate.
  • Every successful and failed approval is written to the administrator audit log.
